# Data Pembeli - Format: NAMA|NIK|EMAIL|NO_WA|QTY|EVENT_URL|LOKASI|PG_METHOD|WAR_TIME
#
# QTY        = jumlah tiket per orang (1-3)
# EVENT_URL  = link event (wajib)
# LOKASI     = nomor paket tiket (lihat di halaman event)
# PG_METHOD  = metode pembayaran (711=QRIS)
# WAR_TIME   = jam war WIB (HH:MM:SS), kosong = langsung gas
#
# Baris yang dimulai # atau kosong akan di-skip
# MODE otomatis PARALEL untuk semua akun
#
# Contoh:
BUDI SANTOSO|3301234567890001|integralflorance@wshu.net|081234567890|1|https://sites.explorefomo.id/VikingFest2026|1|711|
